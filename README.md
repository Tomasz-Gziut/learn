# Świat po II wojnie światowej

Polskojęzyczna aplikacja do powtórki historii w formie notatek, chronologii, słowniczka i losowanego quizu ABC.

## Uruchomienie

Wymagany jest Node.js. W katalogu projektu wykonaj:

```sh
npm install
npm run dev
```

Vite poda adres lokalnej strony w terminalu.

## Zawartość

- pięć działów z przyczynami, przebiegiem i skutkami wydarzeń;
- wyszukiwarka notatek i pojęć;
- chronologia wydarzeń z lat 1945–1994;
- słowniczek pojęć;
- quiz z pulą 84 pytań, losujący 20 różnych pytań na rundę;
- natychmiastowa informacja zwrotna i wynik po zakończeniu rundy.

## Sprawdzenie i build

```sh
npm run check
npm run build
```

Linki do wykorzystanych źródeł historycznych i instytucjonalnych znajdują się w aplikacji. Oryginalne zdjęcia stron podręcznika nie są częścią repozytorium.
