# Atlas nauki

Polskojęzyczny hub do nauki, który porządkuje materiały według przedmiotów i działów. Z katalogu można przejść do historii świata po II wojnie światowej lub działu fizyki atomowej.

## Uruchomienie

Wymagany jest Node.js. W katalogu projektu wykonaj:

```sh
npm install
npm run dev
```

Vite poda adres lokalnej strony w terminalu.

## Zawartość

- katalog przedmiotów: Historia i Fizyka;
- pięć działów z przyczynami, przebiegiem i skutkami wydarzeń;
- wyszukiwarka notatek i pojęć;
- chronologia wydarzeń z lat 1945–1994;
- słowniczek pojęć;
- quiz z pulą 93 pytań obejmujących wszystkie pojęcia i działy, losujący 20 różnych pytań na rundę;
- każda runda zawiera co najmniej jedno pytanie z każdego działu;
- natychmiastowa informacja zwrotna i wynik po zakończeniu rundy;
- dział fizyki atomowej z siedmioma lekcjami, 19 pojęciami oraz 12 pytaniami z kluczem odpowiedzi;
- lekcje fizyki obejmują budowę jądra, promieniowanie termiczne, fotony, fotoefekt, fale materii, widma i lasery.

## Sprawdzenie i build

```sh
npm run check
npm run build
```

Linki do wykorzystanych źródeł historycznych i instytucjonalnych znajdują się w aplikacji. Oryginalne zdjęcia stron podręcznika nie są częścią repozytorium.
